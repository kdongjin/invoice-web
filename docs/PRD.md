# 노션 연동 견적서 뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 노션(Notion)에 입력한 견적서를 클라이언트가 로그인 없이 고유 링크로 웹에서 확인하고 PDF로 다운로드할 수 있게 한다.
**사용자**: 노션으로 견적서를 작성·관리하는 프리랜서/소규모 사업자(관리자)와, 공유 링크를 받아 견적서를 확인하는 클라이언트.

## 🚶 사용자 여정

```
1. 로그인 페이지
   ↓ 이메일/비밀번호 입력 후 로그인 버튼 클릭

   [계정 없음] → 회원가입 페이지 → 가입 완료 → 로그인 페이지로 복귀
   ↓

2. 견적서 목록 페이지
   ↓ "노션에서 동기화" 버튼 클릭 → 목록 갱신
   ↓ 특정 견적서의 "공유 링크 복사" 버튼 클릭 → 링크가 클립보드에 복사됨
   ↓ (카카오톡/이메일 등 외부 채널로 클라이언트에게 링크 전달)

3. 견적서 상세 페이지 (클라이언트, 별도 진입)
   ↓ 공유 링크로 직접 접속 (로그인 불필요)
   ↓ 견적 항목·합계·유효기간 확인
   ↓ "PDF 다운로드" 버튼 클릭

4. [완료] PDF 파일이 클라이언트 기기에 저장됨
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F001]** | Notion 데이터 동기화 | 지정한 노션 데이터베이스에서 견적서 항목·금액·클라이언트명 등을 가져와 저장 | 노션이 유일한 데이터 입력 도구이므로 서비스의 전제 조건 | 견적서 목록 페이지 |
| **[F002]** | 웹 견적서 조회 | 클라이언트가 공유 링크로 접속해 견적 항목·합계·유효기간을 웹에서 확인 | 서비스가 해결하려는 핵심 문제(브랜딩된 웹 확인) | 견적서 상세 페이지 |
| **[F003]** | PDF 다운로드 | 견적서 상세 페이지 내용을 PDF 파일로 즉시 다운로드 | 서비스가 해결하려는 핵심 문제(문서 형태 보관/전달) | 견적서 상세 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F010]** | 기본 인증 | 관리자 회원가입/로그인/로그아웃만 | 견적서 목록 조회·동기화 기능을 보호하기 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **[F011]** | 공유 링크 발급 | 견적서별로 추측 불가능한 고유 링크를 생성하고 복사 | 클라이언트에게 견적서 접근 경로를 전달하기 위한 필수 기능 | 견적서 목록 페이지 |

### 3. MVP 이후 기능 (제외)

- 클라이언트 계정 및 권한 관리
- 견적서 승인/코멘트 기능
- 다국어 지원
- 여러 관리자 간 협업 기능
- 노션 외 타 데이터소스 지원
- 결제 연동

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 시 인증 메뉴

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 인증 전용 진입 페이지 |
| **진입 경로** | 비로그인 상태에서 "로그인" 메뉴 클릭, 또는 회원가입 완료 후 자동 이동 |
| **사용자 행동** | 이메일/비밀번호를 입력하고 로그인 |
| **주요 기능** | • 이메일/비밀번호 로그인 폼<br>• 로그인 실패 시 에러 메시지 표시<br>• 회원가입 페이지로 이동 링크<br>• **로그인** 버튼 |
| **다음 이동** | 성공 → 견적서 목록 페이지, 실패 → 에러 표시 |

### 회원가입 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 시 인증 메뉴

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 계정 생성 전용 페이지 |
| **진입 경로** | 로그인 페이지의 "회원가입" 링크 클릭 |

| **주요 기능** | • 이메일/비밀번호 입력 폼<br>• 입력값 유효성 검사<br>• **가입하기** 버튼 |
| **다음 이동** | 성공 → 로그인 페이지 |

### 견적서 목록 페이지

> **구현 기능:** `F001`, `F011` | **인증:** 로그인 필요

| 항목 | 내용 |
|------|------|
| **역할** | 노션에 등록된 견적서를 확인하고 클라이언트 공유 링크를 관리하는 관리자 전용 페이지 |
| **진입 경로** | 로그인 성공 후 자동 이동, 이후 "견적서 목록" 메뉴 클릭 |
| **사용자 행동** | 노션 데이터 동기화 실행, 견적서별 공유 링크 복사 |
| **주요 기능** | • 동기화된 견적서 목록 표시(클라이언트명·제목·동기화 시각)<br>• **노션에서 동기화** 버튼<br>• 견적서별 **공유 링크 복사** 버튼<br>• **로그아웃** 버튼 |
| **다음 이동** | 복사된 공유 링크는 외부 채널(카카오톡/이메일 등)로 클라이언트에게 전달 |

| **주요 기능** | • 회사 정보/로고 표시<br>• 견적 항목·수량·단가·합계 테이블<br>• 유효기간 표시<br>• **PDF 다운로드** 버튼 |

## 🗄️ 데이터 모델

### Admin (관리자 계정)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| email | 로그인 이메일 | string |
| password_hash | 비밀번호 해시 | string |
| created_at | 계정 생성 시각 | timestamp |

### Quote (견적서)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| notion_page_id | 원본 노션 페이지 ID | string |
| admin_id | 소유 관리자 | → Admin.id |
| client_name | 클라이언트명 | string |
| share_token | 추측 불가능한 공유 링크 토큰 | string |
| synced_at | 마지막 동기화 시각 | timestamp |

### QuoteItem (견적 항목)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| quote_id | 소속 견적서 | → Quote.id |
| item_name | 품목명 | string |
| quantity | 수량 | number |
| unit_price | 단가 | number |

## 🛠️ 기술 스택 (최신 버전)

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router) - React 풀스택 프레임워크
- **TypeScript 5.6+** - 타입 안전성 보장
- **React 19** - UI 라이브러리 (최신 동시성 기능)

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크
- **shadcn/ui** (radix-nova 프리셋) - 고품질 React 컴포넌트 라이브러리
